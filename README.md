# Survey Form

A simple survey form built purely on HTML.

## About
A multi-section survey form that collects personal information,
address details, and feedback from participants.

## Features
- Personal info section (name, age, gender, email, phone)
- Address section with pincode validation
- Feedback section with radio buttons and a rating slider
- Built-in form validation across all required fields
- Reset and Submit buttons

## What I used
- HTML5 semantic elements
- Various input types — text, number, email, tel, radio, range
- Select dropdowns
- Fieldsets and legends for structure

## What I learned
- How to group form sections meaningfully with fieldsets
- Using pattern and required attributes for validation
- Linking labels to inputs correctly
- Working with different input types and when to use each# survey-form
A student survey form built using pure HTML — part of my web development journey.
